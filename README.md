# MedicalChatbot-Phi3.5

## Getting Started
1. Create virtual environment
```python
python -m venv venv
```

2. Activate virtual environment
```python
source venv/bin/activate
```

3. Install Required packages
```python
pip install -r requirements.txt
```

## Run Gradio App
```python
python app.py
```
